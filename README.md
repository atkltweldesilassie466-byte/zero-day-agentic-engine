# ⚔️ Zero-Day Agentic Engine 🛡️
An Autonomous Dual-Agent Cyber Warfare & Self-Healing Defense System powered by Google Gemini AI.

## 💡 Problem Statement
Zero-Day security vulnerabilities leave production systems exposed for hours or days while human engineers analyze attacks and manually write patches.

## 🚀 The Solution
**Zero-Day Agentic Engine** introduces an autonomous multi-agent defense platform:
- **🔴 Red Team Agent:** Scans code repositories, identifies zero-day security bugs, and dynamically simulates exploit payloads.
- **🟢 Blue Team Agent:** Intercepts real-time attack telemetry, synthesizes zero-trust virtual patches, and refactors vulnerable code instantaneously without human intervention.

## 🛠️ Tech Stack
- **AI Brain:** Gemini 2.5 Flash API
- **Frontend & Engine:** HTML5, CSS3 (Cyber Dark Neon UI), JavaScript (Async Fetch API)
- **Deployment:** GitHub Pages

## 📦 How to Run Live
1. Open the GitHub Pages URL.
2. Provide your Gemini API Key (`AIzaSy...`).
3. Input target Python code and click **Launch Autonomous Cyber Attack & Defense**.
